# Experiment records

Create one directory per meaningful experiment using `expNNN_descriptive_name`. Snapshot the exact resolved configuration as `config.yaml`, explain intent and conclusions in `notes.md`, store per-dataset results under stable dataset identifiers, and put cross-dataset outputs in `summary/`.

Completed results are historical records. Do not overwrite them by default. Large checkpoints and logs are ignored; small metrics, tables, notes, and configuration snapshots should be committed.
